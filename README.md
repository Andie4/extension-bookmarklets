# Extension A11y WebCheck

L'extension regroupe des bookmarklets de test d'accessibilité. 

## Prise en main :
Pour récupérer l'extension il faut : 
1. Télécharger le dossier extensions-bookmarklets
2. Entrez cette URl dans le navigateur Firefox "about:debugging"
3. Cliquez sur "Ce firefox"
4. Cliquez sur "Charger un module complémentaire temporaire..."
5. Sélectionnez le fichier "manifest.json"
6. Cliquez sur l'icon des extensions de firefox <img src="medias/extensions.png">
7. Vous pouvez dès à présent voir l'icon de l'extension et cliquer dessus pour l'utiliser. 


## Environnement de travail :
Cette extension est uniquement fonctionnelle sur Firefox.
